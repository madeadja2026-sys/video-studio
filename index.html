Catatan penggunaan
  • Ekspor menggunakan mesin FFmpeg WebAssembly yang dimuat dari internet; koneksi internet diperlukan untuk pertama kali.
  • Proses video besar bisa lambat atau kehabisan memori di HP. Untuk video panjang, gunakan komputer.
  • File media diproses di browser; aplikasi ini tidak mengunggah media ke server milik aplikasi.
  • Fitur subtitle tertanam bergantung pada dukungan subtitle di mesin FFmpeg yang dimuat. Jika gagal, ekspor ulang tanpa opsi subtitle tertanam.
  • Versi awal belum memiliki akun, penyimpanan cloud, efek kompleks, atau generator video AI.
